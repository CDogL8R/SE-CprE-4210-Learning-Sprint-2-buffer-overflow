Stack Frame Architecture
In 32-bit x86 C programs, memory for local variables is allocated on the stack. The stack grows **downward** toward lower memory addresses, but functions like strcpy() write **upward** toward higher memory addresses.
EBP and EIP Registers
  • Saved EBP (Base Pointer): Preserves the caller's stack frame pointer.
  • Saved EIP (Instruction Pointer): Holds the return address where execution resumes after the function completes.
Stack Canary Mitigation
A Stack Canary is a random secret value placed between local variables and control registers. Before returning, the compiler checks if the canary value was altered. If modified, the program terminates immediately with *** stack smashing detected ***.
Safe vs Unsafe APIs
Unsafe functions like strcpy(), gets(), and sprintf() do not check target buffer sizes. Safe equivalents like strncpy() specify a maximum length parameter to prevent overflow.
